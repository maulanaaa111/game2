Pendaftaran Domain di Firebase

Firebase memblokir Google Login dari domain ini demi keamanan. Salin domain di bawah ini dan daftarkan ke Firebase Console Anda:

  1. Buka Firebase Console
  2. Pilih proyek jurnal-9546c
  3. Masuk ke menu Authentication → tab Settings
  4. Pilih Authorized domains → klik Add domain
  5. Tempel (Paste) domain yang sudah disalin di atas, lalu klik Save

💡 Tips: Anda tetap bisa menggunakan aplikasi dalam Mode Demo / Penyimpanan Lokal jika belum ingin mendaftarkan domain saat ini.
